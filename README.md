# Chiki's Dessert 🐶🥟

Landing page y carta interactiva de **Chiki's Dessert**: empanadas horneadas con cariño y limonadas naturales en San Antonio de Pachacamac.

- Carta con filtros (Clásicas, Premium, Limonadas)
- Packs y Combo del Mes con selección de sabores
- Carrito guardado en el navegador (localStorage)
- Pedido enviado por WhatsApp con el detalle armado

Hecho solo con HTML, CSS y JavaScript, sin backend. Los precios y productos se editan en el objeto `CONFIG` al inicio del `<script>` en `index.html`.
